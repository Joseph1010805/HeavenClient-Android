# What the server says that the client does not hear

Generated by `tools/packet_gap.py`. Regenerate it after adding handlers.

- Messages the server can send: **307**
- Handled by the client: **85**
- Not handled: **222**
- Of those, already written in OpenStory: **151** (a port, not a rewrite)

**This only finds one kind of hole.** A packet nobody reads is easy
to count. A packet that is read *wrongly*, and silently, does not
appear here at all - and those have been most of the real bugs. The
client also prints `Unhandled packet detected, Opcode: N` while you
play, and anything seen there outranks anything guessed at here.
